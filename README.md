# Superstore Sales Performance Analysis

## Business Problem
How can Superstore improve its sales performance by analyzing categories, regions, customer segments, and sales trends?

## Objective
Analyze sales data and provide business recommendations.

## Tools Used
- Google Sheets
- SQL
- GitHub

## Workflow
1. Data Collection
2. Data Cleaning
3. Data Analysis
4. Data Visualization
5. Business Insights
6. Recommendations

## Key Findings
- Technology generated the highest sales.
- Consumer segment contributed the largest revenue.
- West region performed best.
- South region needs improvement.

## Recommendations
- Invest more in Technology.
- Improve marketing in the South region.
- Focus on Consumer customers.

## Conclusion
This project demonstrates an end-to-end analytics workflow from raw data to actionable business insights.
